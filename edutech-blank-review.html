2. 수업체제 설계

  • 의미
    정답 확인 (단권화 원문)

    교수설계(어떻게 가르칠 것인가)를 체제의 관점에서 접근. 수업을 하나의 체제로 보고, 관련된 모든 구성요소들을 '투입–산출–환류' 관계로 파악.

  • 효과 (3)
    정답 확인 (단권화 원문)

    명·연·실

    1. 명확한 목표 진술 : 후속계획 및 실행단계를 효과적으로 진행.
    2. 교수 설계의 각 단계를 연관 : 효과적인 교수 전략을 고안.
    3. 실험적·반복적 과정 : 오류를 지속적으로 수정·보완
  • 특징 (4)
    정답 확인 (단권화 원문)

    문·총·맥·가

    1. 문제 해결 지향적
    2. 총체적인 접근 : 관련된 구성요소들 총체적으로 고려.
    3. 투입과 산출 : 일련의 순서가 있으며, 전 단계가 다음 단계에 영향을 준다. (②③④ = 유기적 관계)
    4. 상호작용 : 모든 구성 요소들은 서로 연결. 상호작용
    5. 맥락 중시 : 사회문화적·역사적 맥락.
    6. 가치 지향적 : 수업 설계자나 관련 이해집단의 가치판단이 개입. 적극적으로 수용.

학습 과제 분석

  • 3가지 분석의 의미. 가네와 연결.
    정답 확인 (단권화 원문)

    학습과제 분석 = 학습목표 분석 + 하위 기능 분석

    1. 위계분석 (지적기능. 운동기능) : 목표 학습에 필수적인 선행(하위) 기능을 "이 단계를 배우려면 무엇을 먼저 할 수 있어야 하는가?"라고 질문하며 아래로 따내려가는 분석. 지적 기능은 문제해결 → 원리 → 개념 → 변별 순으로 내려감. (변개원문 역방향)
    2. 군집 분석 (언어 정보) : 위계가 없는 언어 정보를 의미있는 범주로 묶는 분석.
    3. 통합 분석 : 위계 분석과 군집 분석을 동시에 사용. ex) 태도학습은 선택하기 위해서는 지적 기능. 운동 기능 또는 언어정보 수반이 일반적. (태도 목표 = 통합 분석)

4. 교수자 중심 수업과 수업설계

    정답 확인 (단권화 원문)

    (단위 수업 설계. 구체적 전략과 방법 / cf. 수업체제 설계 = 설계 과정에 대한 지침 제시)

    1. 설계 지향적. 처방적 (기술적 X ← 일반이론)
    2. 수업의 방법 + 수업 방법이 사용되는 상황을 알려줌
    3. 구체적. 세분화된 하위요소 제공 → 적용이 쉬움.
    4. 확률적. (결정론 X) 목표달성 기회를 증가시킴.

    → 위 4특징을 제시한 라이겔루스 본인이, 자신의 '정교화 이론'으로 그 조건을 직접 실천함 (아래 항목과 한 서사로 연결)

  • 라이겔루스 — 교수 3대 변인 · 조직전략(미시/거시) · 정교화 이론 7전략
    정답 확인 (단권화 원문)

    교수 3대 변인 (조방결) : 조건(condition) – 방법(method) – 결과(outcome, 효과성·효율성·매력성 ← ISD와 같은 개념)

    방법 변인의 하위 4 : 조직전략 / 전달전략(매체·자료로 언제 어떻게 제시) / 관리전략(설계~평가 관리)

    조직전략의 두 층위 : 미시적(하나의 아이디어를 어떻게 조직 — 메릴의 내용요소전시이론) vs 거시적(여러 아이디어를 어떤 순서로 — 라이겔루스 정교화 이론 본인 것)

    가네와의 관계 : 라이겔루스는 가네의 9사태가 개략적일 뿐 구체적 방법(예: ④자극 제시, ⑤학습안내를 어떻게 할지)을 충분히 제시 못했다고 비판 → 그 공백을 메우려 조직전략을 정교화

    정교화 이론 핵심 이미지 : 줌 렌즈 비유(전체 개요를 광각으로 먼저 보여준 뒤 부분을 줌인, 다시 광각으로) + 정수(epitome, 가장 단순·대표적인 최초 개요) + 단순→복잡으로 확대

    학, 종, 선, 정, 요, 인, 비, 리!

    1. 정교화 계열(오늘 배울 것) : 단순(쉬운) → 점점 복잡(어려운). 유형: 개념적·절차적·이론적 정교화
    2. 선행학습 계열 : 선행학습 요소를 쉬운 것→어려운 것, 단순→복잡으로 계열화
    3. 요약자(단원 끝) : 학습 내용을 체계적으로 복습하도록 제시
    4. 종합자(오늘 배운 것) : 단일 유형 아이디어들의 관계를 정의·통합
    5. 비유(오늘 배울 것) : 새 아이디어를 학습자에게 친숙한 아이디어와 연관지어 설명
    6. 인지전략 활성자 : 다양한 인지전략을 명시적으로 활용하도록 제시
    7. 학습자 통제 : 학습자가 자신의 학습에서 선택권·통제력(자율성)을 가짐

    내적 : 주동선 의장, 탐색하고 수비하고, 피해!
    외적 : 주목, 선자는 안수의 피로 평화의 파도를 만들었다.

  • 켈러의 학습 동기 설계 이론 — B=f(P&E)의 의미? 교사가 개입할 수 있는 설계 (3)
    정답 확인 (단권화 원문)

    (거시적 이론) 노력(동기의 직접 지표) → 수행(실제 성취) → 결과(보상. 감정반응) · 결과에서 개인적 변인(P)으로 인지적 평가가 되돌아옴.

    B = f(P&E) = 행동은 개인적 특성(P)과 환경(E)의 상호작용에 의해 나타난 결과.

    1. 동기 설계 : 긍정적 피드백. 칭찬 등 — 노력에 개입
    2. 학습 설계 : 학습자 동기 수준에 따라 적절한 내용 선택·추천 — 수행에 개입
    3. 우연성 설계 : 노력이 수행·결과와 밀접하게 연관되었다는 확신 — 결과에 개입

    ↓ 이를 기초로 한 미시적 설계 'ARCS 모형'

  • ARCS 모형 — 4요소와 각 하위요소
    정답 확인 (단권화 원문)

    A (Attention) 주의 : ① 지각적 주의 환기 — 감각을 치는 것. 주의! 많은 자극은 오히려 주의를 분산시킴 (남용 말 것) ② 인식적 주의 환기 — 머리를 치는 것. 지적 호기심. ③ 다양성.

    R (Relevance) 관련성 : ① 친밀성. ② 목표 지향성 (목표의 실용성, 목표를 스스로 고르게 함) ③ 필요나 동기와의 부합성 (성취욕구. 소속욕구 등)

    C (Confidence) 자신감 : ① 지각된 능력 ② 지각된 조절감 ③ 성공에의 기대감 ⇐ 전략 : 학습의 필요조건 명시 / 성공 기회 제시 / 개인적 조절감 증대

    S (Satisfaction) 만족감 : ① 자연적 결과 ② 외적 보상(긍정적 결과) ③ 공정성

    주의! 지인 다 불렀나? 친목도 필수다. 필조성에 자긍 공을 던져라!

  • 객관주의 vs 구성주의 — 6가지 기준(지식·학습·교사·과제·평가·교수)으로 비교
    정답 확인 (단권화 원문)

    객관주의 : 외부에 객관적으로 존재(지식) / 지식의 수용·복제(학습) / 전달자(교사) / 탈맥락적·분절적(과제) / 결과 중심·정답 일치(평가) / 교수자에 의해 기존의 진리가 전달되는 것(교수)

    구성주의 : 학습자가 능동적으로 구성 / 경험에 의해 개발되는 개인적 해석 / 조력자·촉진자 / 실제적·맥락적 / 과정 중심·구성의 관찰 / 학습자가 세상에 대한 의미를 구성하도록 보조·지원하는 것. 세계에 대한 의미 구성 방법을 보여줌.

    객관주의 = 지식은 학습자 외부에 객관적·보편적으로 존재, 교육은 그 지식을 전달하는 것 / 구성주의 = 지식은 경험을 바탕으로 능동적으로 구성, 학습은 개인의 경험과 맥락 위에서 의미를 만드는 과정

  • 인지적 구성주의(피아제) vs 사회적 구성주의(비고츠키) — 핵심 개념?
    정답 확인 (단권화 원문)

    피아제 : 학습 = (인지적 혼란이나 모순을 겪었을 때) 동화와 조절을 통해 인지 구조를 개편하는 과정. 동화 = 기존 스키마에 맞춰 수용 / 조절 = 스키마 자체를 수정 구성 장소 = 개인의 머릿속. 상호작용은 자극일 뿐, 구성은 개인이.

    비고츠키 : 학습 = 사회적으로 맥락화된 지식을 자신의 시각에 의해 내면화하는 과정. 구성 장소 = 사회적 상호작용. 지식은 언어를 매개로 사회에서 구성 → 개인 내면화.

    ZPD(근접발달영역) : 실제적 발달 수준(혼자 해결 가능)과 잠재적 발달수준(도움 받으면 가능) 사이 영역. ZPD 내 과제수행 지원을 위해 유능한 타인이 제공하는 일시적 지원 = 스캐폴딩(비계). 비계는 철거를 전제하고 세움.

  • 구성주의적 수업 설계 원리 (6)
    정답 확인 (단권화 원문)

    학실문 교협평 : 확실한 문이다! 교활하게 협조해서 평! 터트려라

    1. 학습자 중심의 학습환경
    2. 실제적 과제와 맥락 강조 — 유의미한 학습을 위해서는 지식이 제공되는 맥락이 실제처럼 복잡하고 비구조적이어야 함. 과제도 실제적이어야.
    3. 문제 해결 중심의 학습 — 학습자들이 학교에서 배운 지식을 실제 상황에 적용하지 못하는 이유는 지식과 맥락을 분리하여 학습했기 때문임.
    4. 교수자 역할 — 코치. 촉진자
    5. 협동 학습의 강조
    6. 평가의 의미 및 원리 변화.

    3. 자기 주도적 학습 (정보수집)

    5. 문제 해결안 발표
    6. 학습 결과 정리 및 평가.

    상기해고

    1. 다양한 상호작용을 촉진
    2. 사회적 기술 습득을 도움

    4. 고차원적 사고력을 기름

    ⇒ 의견을 상호 교환하고 관점을 비교하는 과정 속에서 상호 협력과 자기주도성을 함양, 논제에 대한 심화학습. But! 교수자는 준비·계획·진행에 많은 시간·노력. 산만·피상적 대화, 발언 독점·침묵 우려.

    2. 객체·방식 : 기존 수업방식과 상충 — 관찰·통제 불가. 자율성↑ 딴짓

    4. 규칙 : 학교 규칙과 상충 — 스마트폰 사용 금지 → BYOD 곤란. 예산·행정 절차. 법규
    5. 공동체 : 학교 문화와 상충 — 온라인 학습에 대한 부정적 인식. 입시 위주 문화.
    6. 분업 : 역할의 변화 — 교사도 콘텐츠 개발. 온라인 소통을 새로 배워야. 학생 자기주도역량 필요.

    정답 확인 (단권화 원문)

    유의미학습 축 : 능동적. 협력적. 구성적. 실제적. 목적지향적 (능협구실목) / 통합 축 : 도입. 채택. 적응. 융합. 전환 (도채적융전)

    능글맞은 협동조합장이 구실을 만들어 목돈을 챙기고 / 도망친 채무자가 적반하장으로 융자까지 받아 전원주택을 샀대.

    ★ 시사점 : 경험·전문성이 축적될수록 교수자중심→학습자중심. 테크놀로지→학습초점. 새로운 방식으로 유의미학습.

    1. 도입 : 수업내용 전달 목적으로 T 사용. T 사용을 교수자가 결정
    2. 채택 : 모두 동일한 T 사용. 교수자의 안내에 따라 일정한 절차로 과제 수행.
    3. 적응 : T를 개념적으로 이해. 독립적으로 사용 가능. 다양한 방식으로 T 사용.
    4. 융합 : 다양한 T가 교수학습 활동과 유연하게 통합. 학습자가 언제 어떤 도구 사용할지 스스로 결정
    5. 전환 : 고차적 학습활동에 새롭고 광범위한 방식으로 참여. 교사는 T 사용 안내·촉진.

    배경 : 교수자의 지식. 자기효능감. 교육에 대한 신념이 영향을 미침

    구성 : TK·PK·CK + 교집합 TPK·TCK·PCK + 중앙 TPACK, 전체를 둘러싼 맥락

    시사점 : 세 지식이 구체적 맥락 안에서 통합될 때 효과적 (테크놀로지 지식이 많다고 테크 활용 수업을 잘하는 것 X)

    수업설계 : ① 수업목표 결정 ② 테크놀로지와 교육활동 선택 ③ 성찰·실행·수정

  • 테크놀로지 활용 수업 역량 개발 (4)
    정답 확인 (단권화 원문)
    1. 수업 설계 및 실행 경험 성찰. 자신에게 부족한 지–기–태 무엇인지 파악
    2. (성찰을 통해 부족한 점 발견 후) MOOC 활용 자기주도학습
    3. 교원학습공동체나 동아리 참여
    4. 교육 프로그램(연수) 참여. (교사가 이끄는 교실혁명 연수. AIEDAP 주관 연수 프로그램 등…)

9. 테크놀로지 활용 수업의 실제

  • 모바일 러닝의 특성 및 스마트 교육의 방향성 (5)
    정답 확인 (단권화 원문)

    특성 : 언제 어디서나 개별화된 학습 가능. 학교 안팎의 실제적 맥락 연결[cite: 1].

    스마트(SMART) 교육의 방향성[cite: 1]

    1. S (Self-directed) 자기주도 학습 : 학습자가 지식 수용자에서 생산자로 변화[cite: 1].
    2. M (Motivated) 동기화된 학습 : 체험, 문제해결 등을 통해 내재적 흥미 유발[cite: 1].
    3. A (Adaptive) 적응적 학습 : 학습자 수준과 선호도에 맞는 맞춤형 개별화 학습 제공[cite: 1].
    4. R (Resource enriched) 풍부한 자료 기반 : 클라우드 등을 통한 풍부한 콘텐츠 활용[cite: 1].
    5. T (Technology embedded) 기술이 내재된 학습 : 정보통신 인프라 기반의 환경 구축[cite: 1].
  • 게임화(Gamification) — 정의 및 게임의 6요소
    정답 확인 (단권화 원문)

    정의 : 게임이 아닌 것(수업)에 게임의 요소나 원리를 적용하는 것. (cf. 기능성 게임: 처음부터 교육 목적으로 개발된 게임 자체)[cite: 1].

    수업에 적용할 게임 요소 (목규피보레스)[cite: 1]

    1. 목표 : 명확하고 구체적인 목표 제시[cite: 1].
    2. 규칙 : 경쟁과 협력을 유도하는 규칙[cite: 1].
    3. 피드백 : 실패해도 재도전할 수 있는 기회와 명시적 피드백 제공[cite: 1].
    4. 보상 체계 : 포인트, 배지, 리더보드 등 (단, 과도한 외적 보상 치중 시 내적 동기 감소 우려)[cite: 1].
    5. 레벨 : 난이도에 따른 점진적 상승[cite: 1].
    6. 이야기(스토리) : 몰입을 돕는 내러티브[cite: 1].
  • 인공지능(AI) 활용 수업 — ITS vs ILE
    정답 확인 (단권화 원문)

    지능형 튜터링 시스템 (ITS) : 객관주의 패러다임. 잘 정의된 문제(well-structured problem)를 중심으로 지식과 기술을 학습하는 데 효과적[cite: 2]. (교수 모델, 학습자 모델, 영역 모델로 구성)[cite: 2].

    지능형 학습환경 (ILE) : 구성주의(조나센 CLE) 패러다임. 학습자가 스스로 지식을 구성하도록 돕는 환경[cite: 2]. AI가 교사를 도와 모델링, 코칭, 스캐폴딩 제공[cite: 2]. (예: '베티의 두뇌' - 학습자가 AI 에이전트를 가르치며 배우는 프로그램)[cite: 2].

  • 플립러닝(Flipped Learning) — 특징 4요소 (F-L-I-P)
    정답 확인 (단권화 원문)

    거꾸로 교실. 사전에 지식을 습득하고, 교실에서는 문제해결 및 협력학습 등 고차원적 활동 수행[cite: 1].

    1. F (Flexible environment) 유연한 환경 : 학습 시간, 공간, 평가 방법의 유연성[cite: 1].
    2. L (Learning culture) 학습 문화 : 교사 중심에서 철저한 학습자 중심의 지식 탐구 문화로 이동[cite: 1].
    3. I (Intentional content) 의도된 내용 : 사전 학습 자료와 본시 활동 간의 유의미한 연계 설계[cite: 1].
    4. P (Professional educator) 전문적 교육자 : 지속적 관찰, 즉각적 피드백, 형성평가를 제공하는 촉진자 역할[cite: 1].
  • 온라인 학습 — 유형 3가지 및 탐구 공동체 모형(CoI)
    정답 확인 (단권화 원문)

    유형 : ① 실시간 쌍방향 중심 ② 콘텐츠 활용 중심 ③ 과제 수행 중심[cite: 1].

    탐구 공동체 모형(CoI)의 3가지 실재감[cite: 1]

    1. 인지적 실재감 : 학습자가 성찰과 대화를 통해 스스로 의미를 구성하는 정도[cite: 1].
    2. 사회적 실재감 : 신뢰할 수 있는 환경에서 자신의 마음을 열고 소통하는 정도[cite: 1].
    3. 교수 실재감 : 인지적, 사회적 실재감을 지원하기 위해 수업을 설계하고 운영하는 교사의 촉진 역할[cite: 1].

10. 수업 과정안 설계

  • 수업 설계 패러다임의 진화 — 객관주의 vs 구성주의
    정답 확인 (단권화 원문)

    전통적 교수자 중심 설계 (가네) : 효율적이고 체계적인 지식 전달에 최적화되어 있으나, 비구조화된 문제해결력과 창의성을 기르는 데 한계가 있음.

    학습자 중심 설계 (디자인 씽킹) : 학습자가 주도적으로 문제를 발견하고 산출물을 만들어내는 구성주의적 환경. (공감하기-정의하기-아이디어-프로토타입-테스트 절차 적용)

  • 과정안 설계 시 핵심 고려사항
    정답 확인 (단권화 원문)

    목표(What)와 방법(How)의 일치, 학습자 수준에 맞는 매체(TPACK) 선정, 과정 중심 평가 및 즉각적 피드백 계획 수립.

11. 수업 실행과 의사소통

  • 쉐논과 쉬람(Shannon & Schramm)의 의사소통 모형
    정답 확인 (단권화 원문)

    교사와 학생 간의 완벽한 정보 전달은 존재하지 않음.

    1. 경험의 장 (Field of Experience) : 교사와 학생의 경험의 장이 중첩되어야 유의미한 소통 가능.
    2. 잡음 (Noise) : 의사소통을 방해하는 물리적, 심리적 요인.
    3. 피드백 (Feedback) : 잡음을 극복하고 오개념을 바로잡기 위한 상호작용 필수.
  • 교사의 효과적인 질문 전략
    정답 확인 (단권화 원문)

    단순 기억을 묻는 '폐쇄형 질문'을 지양하고, 학습자의 발산적/평가적 사고를 촉진하는 '개방형(확장형) 질문' 활용. 질문 후 충분한 '대기 시간' 부여.

  • PBL 및 학습자 중심 환경에서의 튜터(Tutor) 역할
    정답 확인 (단권화 원문)

    단순 지식 전달자가 아닌 학습 촉진자(Facilitator). 팀 내 대인관계 조정(무임승차 방지), 학습 속도 조절, 적절한 인지적 스캐폴딩 제공.
