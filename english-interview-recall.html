안녕하세요, 교수님. 저는 학생들이 생성형 AI를 사용할 때 실제로 무엇을 배우고 있는지 질문하는 교사입니다.

수업에서 한 가지 의문을 발견했습니다. 일부 학생은 AI로 수준 높은 결과물을 만들었지만, 그것을 자신의 말로 설명하는 데 어려움을 겪었습니다.

이 경험을 계기로, 학생들이 AI를 사용하면서도 스스로 이해를 형성할 수 있도록 돕는 학습 활동 설계에 관심을 갖게 되었습니다.

작성 후: 다듬은 답변 확인

Hello, professors. I’m a teacher who asks what students are really learning when they use generative AI.

I currently teach music at Weihai Korean School.

In my classroom, I noticed a puzzle: some students produced high-quality work using AI, but struggled to explain it in their own words.

This led me to become interested in designing learning activities that help students develop their own understanding while using AI.

02 · 교수설계 적용 경험

Can you give an example of applying instructional design?

핵심 흐름: 직접 개발 → 피드백과 수정 → ARCS 관련성 → 설계의 가치

막힐 때: 영어 키워드

first program → prototype → feedback and revision → relevance → words for each class → improvements

한국어 의미 보기

직접 개발한 타자 연습 프로그램 타자수비대를 교수설계 원리를 활용해 개선했습니다. 첫 프로그램이라 초기 버전은 개선이 필요했습니다. RPISD를 공부하며 피드백과 수정의 중요성을 배웠고, 동료 교사와 친구들에게 시제품을 공유해 피드백에 따라 개선했습니다.

또한 Keller의 ARCS 모형 중 관련성을 적용했습니다. 교사가 자기 학급의 단어를 입력하는 기능을 추가했습니다. 타자 연습을 학생들의 수업 내용과 연결하려는 목적이었습니다. 이 경험으로 교수설계가 학습 도구의 구체적 개선을 안내할 수 있음을 알게 되었습니다.

작성 후: 다듬은 답변 확인

I used instructional design principles to improve Taja Guard, a typing practice program I developed.

It was my first program, so the initial version needed improvement. While studying RPISD, I learned the importance of feedback and revision. I shared the prototype with fellow teachers and friends, and improved it based on their feedback.

I also applied the relevance component of Keller’s ARCS model. I added a feature that allows teachers to enter words for their own classes. My aim was to connect typing practice with students’ classroom learning.

This experience showed me how instructional design can guide concrete improvements to a learning tool.

질문별 첫 문장 바꾸기

관심 있는 모형: One instructional design model I find useful is RPISD.

동기 설계: I find Keller’s ARCS model useful because it helps me make concrete design decisions.

기술 활용 경험: I developed a typing practice program called Taja Guard.

지원 동기: Developing Taja Guard made me want to study instructional design more deeply.

표현과 내용 점검
  • 결함: problems / flaws · 초기 버전: initial version / prototype
  • 피드백과 수정: feedback and revision · 개선하다: improve
  • 공유하다: share it with · 피드백에 따라: based on their feedback
  • advice는 불가산명사: their advice (advices 아님)
  • theory = 이론 / model = 모형 / lesson = 수업·교훈
  • 기능 추가는 설계 변화입니다. 동기나 학습 효과는 실제 관찰이나 자료가 있을 때 구체적으로 말하세요.
  • 피드백에 따른 수정 원리 적용과 RPISD 전체 절차 수행은 구분하세요.
